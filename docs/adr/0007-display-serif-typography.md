# ADR-0007: Display serif (Fraunces) for headings, Geist Sans for body

A uniform Geist Sans made the storefront feel template-minimalist. We keep Geist Sans for body text and add the **Fraunces** variable serif (via `next/font`) for headings and display type, with italic accents for hero keywords — an editorial, "designed" look that pairs with the warm luminous palette. The rejected alternative was a bold geometric sans (e.g. Space Grotesk), which read too techy for a lifestyle catalog, and keeping Geist everywhere, which is what made it feel unstyled.
