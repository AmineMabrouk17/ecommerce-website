# AGENTS.md

## Agent skills

### Issue tracker

Issues and specs live as GitHub issues; use the `gh` CLI for all operations. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles map to identically-named labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
